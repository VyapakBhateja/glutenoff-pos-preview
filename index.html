Add your Supabase project URL and publishable key to config.js.

  1. Create Supabase project.
  2. Run supabase/schema.sql in SQL Editor.
  3. Create one ERP user in Supabase Auth.
  4. Put URL + publishable key into config.js.

Never put a secret/service-role key in the browser.
